# ParkSmart — حالة المشروع الحالية

> آخر تحديث: مايو 2026  
> تطبيق Flutter لإدارة وعرض مواقف السيارات (واجهة أمامية — بدون Backend حتى الآن).

---

## نظرة عامة

**ParkSmart** تطبيق واجهة داكنة (Dark Theme) بلون مميز `tealAccent`.  
يبدأ من **تسجيل الدخول** مع قواعد تحقق، ثم ينتقل إلى **لوحة المواقف** مع عرض منظم داخل لوحة سوداء مركزية.

| البند | الحالة |
|--------|--------|
| Framework | Flutter (SDK ^3.12) |
| المنصات | Windows, Web (Chrome/Edge), Android/iOS (جاهز من Flutter) |
| Backend / API | غير مربوط |
| قاعدة بيانات | غير موجودة |
| حسابات ثابتة (Demo) | **محذوفة** — الدخول يعتمد على القواعد فقط |

---

## هيكل المشروع

```
lib/
├── main.dart                    # نقطة الدخول — home: LoginScreen
├── auth/
│   └── auth_validators.dart     # قواعد التحقق للإيميل والباسورد
└── screens/
    ├── auth/
    │   └── login_screen.dart    # شاشة تسجيل الدخول
    └── home_screen.dart         # لوحة المواقف
```

> ملاحظة: يوجد `SplashScreen` داخل `main.dart` لكنه **غير مستخدم** حالياً.

## تدفق التطبيق (Navigation)

```
LoginScreen  ──(تحقق ناجح)──►  HomeScreen
     ▲                              │
     └──────── Sign Out ────────────┘
```

1. **البداية:** `LoginScreen`
2. **بعد Login ناجح:** `HomeScreen` (`pushReplacement`)
3. **Sign Out:** العودة إلى `LoginScreen` (`pushAndRemoveUntil` — لا رجوع للخلف)

## شاشة تسجيل الدخول (`LoginScreen`)

### التصميم
- خلفية **Gradient** داكنة
- مربع تسجيل دخول **في منتصف الشاشة** (محدود العرض، غير ممتد على كامل الصفحة)
- حقول: Email + Password
- زر **Login**
- زر **Create account** (واجهة فقط — بدون وظيفة بعد)

### التحقق (Validation)
الملف: `lib/auth/auth_validators.dart`

لا يوجد إيميل/باسورد افتراضي مخزّن. أي بيانات **تمرّ القواعد** تسمح بالدخول.

#### قواعد الإيميل
| الشرط | التفاصيل |
|--------|-----------|
| غير فارغ | `Enter your email.` |
| صيغة صحيحة | Regex |
| مزوّد مدعوم | gmail, googlemail, hotmail, outlook, live, yahoo, icloud, protonmail, aol |
| نطاق مدعوم | com, co, net, org, io, edu, me, info (+ اختياري `.xx` ثانوي) |

**أمثلة مقبولة:** `user@gmail.com` · `name@hotmail.co` · `test@yahoo.net`  
**أمثلة مرفوضة:** `test@test.com` · إيميل بدون `@`

#### قواعد كلمة المرور
| الشرط | الرسالة |
|--------|---------|
| غير فارغة | `Enter your password.` |
| 6 أحرف على الأقل | `Min 6 characters.` |
| حرف واحد على الأقل (a-z / A-Z) | `Add a letter.` |
| رقم واحد على الأقل (0-9) | `Add a number.` |

**مثال مقبول:** `Ahmad12`

### رسائل الخطأ (Dialog)
- عند فشل التحقق: **Dialog مربع** (240×240) في منتصف الشاشة
- أيقونة خطأ + رسالة قصيرة + زر **OK**
- الرسائل مختصرة (ليست فقرة طويلة)

## شاشة الهوم (`HomeScreen`)

### الهيدر
- شعار ParkSmart + "Live parking overview"
- زر **Sign Out** (أعلى اليمين) للعودة لتسجيل الدخول

### بطاقات الإحصائيات (3)
| البطاقة | اللون | العدّ حسب الحالة |
|---------|-------|------------------|
| **Fill** | أخضر | `Available` |
| **Empty** | أحمر | `Empty` |
| **Reserved** | كهرماني | `Reserved` |

### لوحة المواقف (اللوحة السوداء)
- مربع **أسود** `#000000` في **منتصف الشاشة**
- عنوان: `Lot A — Ground Floor` + عدد المواقف
- شريط **ENTRY** فوق الشبكة
- شبكة **2×2** للمواقف داخل اللوحة (ليست على كامل الصفحة)

### بيانات المواقف التجريبية (ثابتة في الكود)

| الموقف | الحالة | اللون |
|--------|--------|-------|
| A1 | Available | أخضر |
| A2 | Empty | أحمر |
| A3 | Reserved | كهرماني |
| A4 | Available | أخضر |

### Legend (أسفل الصفحة)
- Available · Empty · Reserved مع نقاط ملونة
